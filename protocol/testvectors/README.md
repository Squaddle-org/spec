# Test vectors

One JSON file per structure. Generated by the `core` repo (`./gradlew generateTestVectors -PspecDir=../spec`
writes into a spec checkout, committed here via PR), verified by `relay` (`make vectors test`) and later the web client.

All binary values base64url without padding. Keys/nonces are fixed in vectors — **test-only**.

Planned files (M0/M1):

| File | Covers |
|---|---|
| `cbor-reject.json` | canonical CBOR encode/decode round trips plus the non-canonical inputs §1 requires a decoder to reject |
| `identity.json` | entropy → mnemonic → master → userKey / userBoxKey |
| `devicecert.json` | DeviceCert CBOR bytes, signing input, sig, plus invalid variants |
| `logentry.json` | genesis, inviteCreate, join, remove, epochRotate; entryHash chain |
| `log-reject.json` | entries that MUST be rejected, with expected error code |
| `op.json` | OpEnvelope: ad bytes, ct, sig, opId |
| `invite.json` | inviteSecret → inviteKey → envelope |
| `request-auth.json` | HTTP request signing input + sig |
| `backup.json` | Argon2id (low params, test only) → backup file bytes |

Format:
```json
{ "name": "genesis-basic", "input": { ... }, "expected": { "cbor": "...", "sig": "...", "hash": "..." } }
```
