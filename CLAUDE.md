# CLAUDE.md — spec repo

This repo is the source of truth for every Squaddle implementation. No code lives here except test vector tooling.

## Rules
- Every change to a signed/encrypted structure, key derivation, or the relay API needs:
  updated `protocol/PROTOCOL.md`, `protocol/relay-api.yaml` (if API), and test vectors — in the same PR.
- Breaking changes bump the struct `v` and, for major versions, the `SQDL1` signing prefix.
- Only libsodium constructions listed in PROTOCOL.md §1. New primitive = new ADR first.
- Canonical CBOR (RFC 8949 §4.2.1) for everything hashed or signed. Never sign JSON.
- New design decision → new ADR in `adr/` (next free number, short: Context / Decision / Consequences).
- Test vectors are generated by `../core` (`./gradlew generateTestVectors -PspecDir=../spec`), never hand-edited.
- `ROADMAP.md` is shared across repos; tick items when the implementing PRs are merged.
